# User-service

### Выбранная сущность User
### Функционал: 
1. Добавлние пользователя
2. Получение пользователя по id
3. Получение карты пользователя
4. Добавление фото пользователя

### Стек технологий
1. Spring Boot
2. Lombok
3. Swagger
4. MinIO
5. Kafka
6. MongoDB

### Спецификация
JSON:API

### Инструкции по запуску:
1. Запускаем приложение
2. Проходим по ссылке http://localhost:8080/swagger-ui/index.html#/
3. Примеры запросов уже будут в сваггере
